# mini-rag

This is a minimal implementation of the RAG model for question answering.

## Requirements

- Python 3.8 or later

#### Install Python using MiniConda

1) Dowemload and install MiniConda from [here](https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh)
2) Create a new environmnet using the following command:
```bash
$ conda create -n mini-rag pyhton=3.8
```
3) Activate the environment:
```bash
$ conda activate mini-rag
```
